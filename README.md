### 主要プロジェクト

| 項目 | Trit Web Application |
| :--- | :--- |
| **開発期間:** | 2025.07 - 2025.08 |
| **使用技術:** | Java (Spring Boot), Python (FastAPI), PostgreSQL, LangChain, RAG, Thymeleaf |
| **担当業務:** | バックエンド全体の設計、AI APIサーバーの構築、RAGロジックの実装 |
| **詳細内容:** | Spring BootとFastAPIを連携させたマイクロサービス構成です。<br>1. **バックエンド**: Spring Securityによるユーザー認証と掲示板機能を実装しました。<br>2. **AIサーバー**: FastAPIでAI専用サーバーを分離し、拡張性を高めました。<br>3. **AI機能**: LangChainとRAGを活用し、特定のデータに基づいた回答を行うチャットボットを構築しました。<br>4. **フロントエンド**: ThymeleafとVanilla JSを使用し、レスポンシブなUIを制作しました。 |
